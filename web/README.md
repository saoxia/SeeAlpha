# SeeAlpha Web 管理端

SeeAlpha 是基于 NautilusTrader 的多资产量化交易系统。本管理端当前提供项目检查、
策略回测、报告及任务管理；产品定位与各市场接入状态见 [项目首页](../README.md#产品范围与当前实现)。

在项目根目录启动：

```bash
.venv/bin/python -m web.server
```

默认监听所有 IPv4 网卡。本机打开 <http://127.0.0.1:8765>；其他设备访问
`http://运行机器的IP:8765`，也支持指向该机器的域名。
需要换端口时添加 `--port 8766`；按 `Ctrl+C` 停止服务及其正在执行的任务。
管理端使用 Python 标准库和现有项目环境，无需安装前端工具或升级依赖。

## 功能

- **总览**：项目检查结果、可用策略、研究报告及最近任务。
  页面每十秒读取已经发布的状态；分别显示各快照的时间，过期状态不能视为当前正常。
- **运维操作**：快速检查、完整检查。
  快速检查包括冻结来源与代码检查，完整检查额外运行全量测试。
- **策略回测**：BTC、ETH 的趋势跟随与均值回归多空入口，共八个选择。
  支持起止日期和 1m/5m 输入，使用策略现行参数。
- **报告中心**：检索已有单策略和组合回测报告，在新窗口打开原交互报告，下载参数和统计。
- **任务记录**：任务状态、输出日志、取消任务和打开新生成的报告。
  记录保存在 `data/web_console/jobs/`，重新打开管理端后仍可查看。

回测日期以 UTC 为准，结束日不包含在内，每次最多 366 天。开始前会根据原策略要求
加载预热数据。只读取已有本地 Catalog，不自动下载或补齐数据；整个区间没有数据时
标记为跳过，部分数据缺失仍遵循现有回测行为，具体范围查看任务日志和报告。
结果统一保存到 `data/reports/backtest/<策略>/<run_id>/`，组合位于其 `portfolio/` 子目录。
每次使用独立运行目录；报告生成代码仍位于 `strategy_python/_report/`。

Web 端同时只运行一个任务，检查最多 30 分钟，回测最多两小时，超时会终止任务。
取消任务会停止该任务的子进程组，已产生的部分文件可能保留，不能视为完成的报告。
异常中断后，未完成记录标记为中断；不会自动恢复回测。

## 访问范围

默认 `--host 0.0.0.0`，可用 `--host 127.0.0.1` 切回仅本机访问，或指定某个网卡地址。
操作保留同源及页面请求凭证校验，允许通过网络 IP 或域名访问；只提供固定动作及报告文件，
不提供任意命令、文件浏览或密钥设置。

网络访问需要登录：用户名 `admin`，首次启动自动生成口令，保存在
`data/web_console/access_password`（仅当前用户可读写）。可用 `--password-file` 指定
已有口令文件，口令至少 16 个字符。页面、接口和报告都需要认证；口令是登录凭证，
不要分享给无关人员。公网使用 HTTPS 反向代理保护登录口令传输。

跨网络访问还取决于 macOS 防火墙、路由器端口映射或反向代理。
监听所有网卡本身不提供公网地址。HTTPS 反向代理应保留原始 Host，
页面操作接受与该 Host 相同的 HTTP/HTTPS Origin，不信任转发头来绕过同源校验。

策略源码、冻结参数、采集启停、自动数据补齐及实盘下单不在此管理端的操作范围内。
研究策略和历史报告仍应按各自的研究说明解读。

## 验证

```bash
.venv/bin/python -m pytest tests/web -q
.venv/bin/python -m pytest -q
```

测试使用独立临时目录，覆盖输入校验、任务互斥与取消、异常退出、状态时效、请求来源
和文件访问边界。

## 模块边界

- `server.py`：HTTP 接口、访问控制、报告浏览及静态资源。
- `jobs.py`：仅供本管理端使用的后台任务、进程组、超时、取消和日志。
- `static/`：页面、CSS 和 JavaScript。

快速检查运行 Ruff 和源码基线测试；完整检查运行 Ruff 和全部 pytest 测试。
检查 worker 由任务管理器调用，不设置独立命令行或运行时目录。
已有任务与访问口令继续保存在 `data/web_console/`，保持原有数据兼容。
