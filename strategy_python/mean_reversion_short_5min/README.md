# 五分钟均值回归做空

只做空，最多两份仓位。当前入口为 `MeanReversionShort5MinStrategy`，静态参数在 `config.py`。

## 当前规则

交易定价指标及 BOLL 首仓过滤均使用已完成的五分钟 K 线。MA99 为 99 根五分钟收盘价的简单移动平均。
距离统一为每根收盘价减去该根同期 MA99，保留正负号。

- **首仓**：在最新 BOLL(20,2) 上轨挂空单。首仓挂单价减去当前 MA99 必须不小于近 48 小时距离 P11，否则不挂单或撤销原首仓单。
- **五分钟首仓过滤**：使用已完成五分钟 K 线及同期 BOLL(20,2)，包含影线。最近下轨触碰时间晚于上轨时允许；上轨更晚则禁止并撤销未成交首仓单。只有下轨记录时允许，无下轨记录或同一根同时触碰两轨时禁止。该条件通过后仍需满足下述触碰次数过滤、P11 过滤及风险检查，加仓不受此过滤影响。
- **首仓触碰次数过滤**：最近 36 根已完成的五分钟 K 线（3 小时），按每根同期 BOLL(20,2) 统计：最高价 ≥ 上轨记上轨触碰 1 次，最低价 ≤ 下轨记下轨触碰 1 次，要求上轨触碰 ≥ 2 次且下轨触碰 ≥ 2 次，两项必须同时满足。同一根同时触碰两轨时，上轨和下轨各记 1 次；连续多根触碰逐根计数。窗口包含最新完整 K 线，必须凑齐 36 根有有效同期 BOLL 的连续 K 线；重复 K 线不累计，数据缺失或时间断档后重新累计。不满足时不挂首仓或撤销未成交首仓单；加仓不受此过滤影响。仍须满足最近下轨触碰晚于上轨的原过滤，同根双轨触碰不会单独解除该限制。
- **最近三次触碰过滤**：最近 3 根发生 BOLL 上轨或下轨触碰的完整五分钟 K 线中，至少 1 根触碰下轨。按每根同期 BOLL 判断，包含影线及等号；未触碰两轨的 K 线不占记录，同根触碰两轨记作一条包含下轨的记录，连续触碰逐根记录。须有 3 条有效触碰记录；重复 K 线不累计，时间断档或无效行情后清空。不满足时不挂首仓或撤销未成交首仓单，加仓不受此过滤影响。与原方向及36根次数过滤共同生效；原方向条件已要求最近触碰为下轨，因此当前组合下这条条件不会额外排除原本可建仓的信号。
- **加仓**：令 `A＝当前持仓均价×1.005`、`D＝上次仓位实际变动时近48小时距离样本 P80～P95 范围内的算术平均值`。若最新 BOLL 上轨 ≥ A，加仓价取上轨；否则取 `max(A, 当前 MA99＋D)`。D 包含分位边界和边界处重复值、保留正负号；每次入场、加仓或减仓的实际成交（含部分成交）后重新锁定，仅行情更新和改单不重置。价格随最新完整五分钟 K 线更新，缺少备用分支所需数据时撤销加仓单。首仓部分成交时先完成首仓，最多持有两份；加仓数量为两份目标数量减当前实际数量（余仓 0.5 份时补 1.5 份），按合约数量步长向下取整；补仓仍须通过周期风险预算检查。由于加仓价至少为均价的 1.005 倍，高于余仓利润保护止损，正常反弹通常先保护退出，无法再补仓。
- **第一止盈价**：`P1＝min(最新BOLL下轨, 最近一次建仓成交价－W)`，其中 `W＝最近240根完整五分钟K线各自同期BOLL上轨减下轨的最小值`（20小时，包含最新完整K线）。使用完整带宽的价格金额，不是半宽或百分比；BOLL有效后累计240根才就绪，重复K线不累计，时间断档或无效行情后重新累计。W随行情滚动，不在成交时锁定；最近一次建仓成交价取首仓、加仓或补仓最新一笔实际成交价，部分成交逐笔更新；减仓、行情更新和改单不改变该成交价，全平后清空。P1随最新指标和最近建仓成交价更新。未就绪或目标价非正时不生成新第一止盈目标，已有保护单保留。
- **第二止盈距离D**：近48小时必须先有576个有效“收盘价－同期MA99”距离样本，然后只保留严格小于0的样本，在筛选后的负值样本中计算P20和P70，取两分位边界之间实际样本的算术平均值（包括边界及重复值）。分位仍按筛选后样本数的 `floor(N×p)＋1` 排名取值，不插值；0和正值不参与。不足48小时或无负值时D未就绪，不生成新第二止盈目标。D随完整五分钟K线滚动更新。
- **止盈状态**：首仓一份时，全部挂第一止盈价P1。加仓后按合约价格精度比较P1与 `P2＝min(最新BOLL下轨, 当前MA99＋D)`：P1>P2时，1.5份挂P1、0.5份挂P2；P2≥P1时，只在P1挂全部当前持仓的只减仓限价单，并撤销原第一止盈单。未成交时随最新完整五分钟K线的价格比较切换挂单方案；全仓止盈单一旦部分成交，锁定全平意图，其余数量继续在更新后的P1限价退出，不再拆单或补仓，也不转市价。分批方案的第一单完成1.5份减仓后，剩余0.5份继续按原P2及余仓止损管理。补仓后重新比较价格安排止盈。第一止盈部分成交期间不补仓；同价或跳空跨越两价时完成全平，不在中间补仓。止盈全平不进入止损恢复等待。P1以最近建仓价为基准，P1和P2都可能高于持仓均价，因此止盈退出不保证盈利。
- **加仓后随时间放宽退出**：最近一次加仓或补仓实际成交后严格超过24小时，进入全仓限价退出并停止加仓。退出价为 `当前开仓均价 × (1＋允许亏损比例)`，默认允许亏损比例为 `min(floor((距上次加仓时间－24小时)/24小时) × 1%, 5%)`：超过24小时按均价，48小时按均价×1.01，72小时×1.02，144小时及以后×1.05。每次源行情K线检查是否跨入新档并更新挂单；普通完整五分钟K线也维护目标。参数 `time_exit_loss_step=0.01`、`time_exit_max_loss=0.05`；将step设为0可复现固定均价退出基线。部分加仓成交逐笔重置计时；减仓、行情更新和改单不重置。仅有首仓、从未加仓不触发。覆盖普通P1/P2安排，部分退出后剩余数量继续按对应价格限价退出，原止损保护继续有效。退出不进入止损恢复等待，亏损比例未包含手续费；达到亏损上限后继续挂限价单等待成交，不强制市价退出。全平后清空计时及档位。
- **余仓止损**：两份持仓在第一止盈点平掉 1.5 份后，止损改为 `min(当前持仓均价, MA20＋0.5σ)`。MA20 和 σ 使用最新完整五分钟 BOLL(20,2) 的中轨和标准差，随行情更新；补仓成交后恢复下一条两份状态的止损。
- **首仓及两份持仓止损**：`当前持仓均价 × 1.6`，即均价上方 60%。实际成交改变持仓均价后刷新止损；行情中的 MA99 和距离分位不影响该止损。触发后市价全仓退出。首仓定仓和加仓风险检查使用同一公式。
- **保护单激活及更新**：首个止盈单完成 1.5 份减仓后立即激活余仓保护。挂单或改单前，按合约价格精度比较新止损与当前可用买价（有报价时优先最新卖一价，否则用最新已观察成交价/源 K 线收盘价）。若市场价已达到或高于买入止损价，直接撤销同周期挂单并市价退出，不先发注定被拒绝的止损改单；否则正常预挂或更新止损单。正常触发与真正下单/改单故障使用不同成交标签，故障日志包含拒绝原因。固定60%止损触发仍进入恢复流程，余仓利润保护触发不进入。
- **止损后等待**：上述固定60%止损全仓退出后，按顺序完成三个阶段：连续五根完整五分钟 K 线最高价严格低于同期 MA99 → 连续五根最低价严格高于同期 MA99 → 再连续五根最高价严格低于同期 MA99。包含影线，触碰不算；同一根只归入一个阶段。止损所在 K 线不计数；方向不满足时仅当前阶段计数归零，已完成阶段保留；均线/行情数据缺失或时间缺口时整个恢复序列重置，重复 K 线不累计。第三阶段完成后解除等待，仍须通过五分钟 BOLL 方向和触碰次数过滤、P11 入场过滤及风险检查。余仓利润保护止损和普通止盈不触发这套等待。
- **定仓**：周期风险预算为账户权益的 30%，使用首仓上轨价和按当前 P80～P95 样本均值及上述价格分支预计的第二价，结合上述止损、入场费率 0.02%、强平费率 0.05% 和成本缓冲 5% 反推每份数量；同时覆盖仅首仓成交后先止损的成本。后续加仓按最新均价、BOLL 上轨、MA99 和锁定距离均值重算价格，仍须通过预算检查。
- **完整样本**：48 小时窗口为 576 个有效距离。分位算法统一采用升序第 `floor(样本数 × 分位比例)＋1` 个值（上限为最后一个），不做插值。P11、P80、P95 分别取 576 个样本的第 64、461、548 个值。
- **指标缺失**：样本未就绪时不建首仓、不加仓。首仓及两份持仓按有效持仓均价维持固定60%止损；余仓遇 BOLL 数据缺口时保留最后有效保护止损，没有有效保护止损则应急退出。撤单在途出现迟到入场成交会进入清理平仓，旧单处理完成前不会开始新周期。

当前没有强制市价退出的最大持仓时间；加仓超过24小时后启用上述随时间放宽的限价退出并停止继续加仓。区间位置、上涨强度、旧恢复系数、旧百分比/多周期/BOLL 加仓方式、账户比例/百分比/BOLL/时间止损、旧分批止盈和固定百分比止盈、固定冷却的代码及参数均已删除。传入这些旧参数会报错。

## 回测

默认 500 USDT 初始资金、5 倍杠杆、HEDGING 模式。预热期仍为 15 天；当前交易所需最长指标窗口为 48 小时距离窗口及前置 99 根均线样本；预热行情只更新指标，不在交易起点前下单。

在项目根目录运行，日期为 UTC，左闭右开：

```bash
uv run python -m strategy_python.mean_reversion_short_5min.backtest \
  --start 2026-08-01 --end 2026-08-08
```

输入周期可选 `--interval 1s`、`1m` 或 `5m`，不同输入粒度可能影响成交模拟。
默认使用本地已有数据；显式传入 `--check-data` 才检查补齐数据。
报告保存至 `strategy_python/_report/backtest/mean_reversion_short_5min/<run_id>/`，包含参数、账户、成交、持仓、汇总和 HTML 报告。

`close_positions_on_stop=True` 表示回测结束时清仓，与持仓时长无关。组合账户通过公共 `portfolio_backtest.py` 接入共享风险预算。
历史报告和已有源码快照保留；旧配置应配合对应历史源码复现，不适用于清理后的当前策略。

- **连续未触下轨止损**：持仓期间连续48根完整5分钟K线，每根最低价都严格高于同期BOLL下轨且严格高于同期MA99，触发全仓限价退出（含余仓）：买入限价为当前持仓均价×1.01，按价格步长向下取整；价格超过该价则等待，进入该价以内才成交。触发后锁定退出意图、取消加仓，后续触碰或指标变化不撤销退出；该限价优先于24小时阶梯退出，60%硬止损与余仓保护仍独立有效。包含影线；最低价≤下轨或≤MA99均清零，只有收盘价在MA99上方不算满足。MA99缺失或无效也清零。仅统计首仓成交之后完整形成的K线，加仓/减仓不重置，清仓重置；数据缺失或时间缺口中断连续计数，重复K线不累计。触发后沿用硬止损的重新入场等待流程，60%价格硬止损继续独立有效。
