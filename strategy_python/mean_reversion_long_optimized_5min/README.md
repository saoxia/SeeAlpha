# 均值回归做多：更深折价入场

[参数计算公式与来源](PARAMETER_SOURCES.md) · [缺乏校准依据的待讨论项](../PARAMETER_QUESTIONS.md)

**评估结论：研究版本：留出期未通过收益改进检验。暂不建议替换原版。**

2025-01-01 至 2026-09-01 留出期，500 USDT 独立起步：原版净收益 52.74，新版 7.90 USDT；分钟收盘权益回撤 25.50% → 24.63%。该区间曾被原策略研究使用。

独立主类：`MeanReversionLongOptimized5MinStrategy`。

选中 `moderate_discount`：布林带标准差倍数从 **2.0 改为 2.25**。假设是：在原有允许做多的环境下，要求更深的短期折价，减少不足以覆盖成本的回归交易，并改善大幅下跌时的入场质量。

默认读取 1 分钟行情，使用完整 5 分钟收盘计算 BOLL(20, 2.25)，在下轨挂首仓限价单。原 MA99 过滤、最多四层加仓、0.5% 止盈、动态风险折减和止损恢复条件保留。周期基础风险比例 0.30、硬止损距离配置 0.25 均未提高。

**`max_holding_hours=48` 实际仅限制首次入场后的加仓窗口，并不是最长持仓期限。** 达到 48 小时后撤销/禁止后续加仓，已有持仓仍由止盈、止损等规则管理。本轮 24/72 小时候选改变的也是加仓窗口。
