# 需要继续讨论的参数与规则

本表不是“这些参数一定无效”的结论。它区分：有逻辑但精确值未校准、有历史筛选证据但可能过拟合、连精细形状都缺少数据支持的规则。当前均保留，暂不进行新一轮拟合。

## 由风险偏好、成本或工程目的决定

- **预算**：MRL基础风险30%与25%价格止损；趋势名义1倍；PBS原类风险.5%/上限1倍、原组合与新版1.5%/3倍。它们需要风险容忍度约束，不必编造市场规律。MRL系数相乘后计划预算可高于30%。
- **成本假设**：MRL入场2bp、强退5bp、损失与费用再加5%缓冲；PBS每边金额7bp预算缓冲。没有依据把7bp唯一分解成某组“真实手续费+真实滑点”，故未用这种算术拆分伪造来源。换市场时核对实际成本；引擎实际扣费与定仓缓冲是两件事。
- **关闭分支**：MA退出.2/.3σ、斜率风险EMA1/scale .1/最大1.5σ/buffer .1σ/倍率1、利润放松scale .01、动态锁利和空头宽度例外。完整字段与活动状态见各策略来源页。默认业绩不能用来证明未使用分支；启用就属于新规则实验。
- **单份时不生效**：额外持仓间距4%。只有开启多份时才需要统计校准。
- **纯记录**：MRL最近26根6小时快照不参与交易。它无需Alpha来源，可以保留为记录字段；不能为了“解释26”而将其接入信号。
- **工程依赖**：预热135/11/21/30天、UTC日线、合约步长、缺口就绪检查等。它们要求数据和实现一致性；不是可随意收益选优的指标。窗口换算不是统计来源。

当前没有删除这些规则，也没有把讨论方案写成交易行为。先决定Q1～Q3是否值得保留复杂形状，再考虑Q11～Q13的跨资产检验，能更直接区分信号依据与历史拟合。
