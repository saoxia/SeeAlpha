# 均值回归多头：收复后的持续走强

独立研究候选，用于检验上一轮“收复后等待回踩下轨”是否留下了再次转弱的交易。

已完成6组完整回放：回撤下降，BTC全期亏损减少，但ETH原费率及部分近期结果退化，未形成跨市场一致改进。详见[结果解释](../_optimization/mrl_recovery_20260922/INTERPRETATION.md)。

研究预设在原成本门槛及连续5分钟跌破／收复确认之外，要求确认后的第一根完整一分钟线收盘高于确认线高点，再提交该分钟收盘上方2bp的限价买单。价格上限向上取整到合法档位；仍在最初确认后5分钟到期，每次确认只尝试一次。重新计算剩余至冻结中轨的空间，目标已越过或不足保守成本预算即放弃。

沿用单层7.5%计划风险预算、25%保护止损、24小时／两倍目标距离退出和中轨重新准入。入场位置变化也会改变目标距离及对应退出距离；不根据更近的退出增加风险预算。

`recovery`是唯一主候选；`control`关闭本轮改动，复现上一轮`reclaim`，仅供工程对照。
