# BTC 假跌破收复研究候选

入场：完整小时最低价跌破此前24小时最低价，且收盘重新收复原通道下沿；等待一分钟后买入。只做多。

退出：固定持有48小时，无价格止损。名义持仓上限为当前权益的20%，数量按0.001BTC向下取整，最低名义额50USDT。初始账户500USDT，不借款。双边按0.05%吃单手续费计算。

`preset.create_config()` 返回冻结退出参数；`preset.run_backtest(minutes, hourly, start, end)` 使用冻结仓位运行。输入时间带UTC时区，分钟和小时数据索引均为K线结束时间。本模块是自建分钟OHLC研究模拟器，不是Nautilus实盘策略适配器。

详细回测与局限见 `../_optimization/btc_entry_strategy_20260916/RESULTS.md`。0.25/0.3倍仓位的近期表现不稳定，最小下单量使仓位影响非线性；不能把本候选解释为已验证的稳定正期望或最佳实盘参数。资金费率、真实盘口和滑点尚未模拟。
