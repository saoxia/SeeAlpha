# trend_following_short_optimized_5min 参数计算与来源

本页对应新版当前默认配置。源码中的计算逻辑和参数取值依据分开记录；有公式不等于精确系数有统计证据。

[统一来源规则与迁移说明](../PARAMETER_SOURCES.md) · [待讨论清单](../PARAMETER_QUESTIONS.md)

## 由行情和账户实际计算的量

- 5分钟MA52/MA99新死叉，外加前一完整日线low破当时BOLL下轨、当日截至信号时刻low破动态BOLL下轨。日线均值和总体标准差只用当时可见价格；当日最新价代替未完成的收盘。不锁存早先盘中条件，不读取未来日收盘。
- 默认小时方向和重入区过滤关闭，但小时模型/偏离模型仍有就绪依赖。不能把未启用过滤的参数解释成当前盈利来源。
- 数量：`floor_step(盯市权益*fraction/入场价)`，读取目标合约步长。
- 峰值毛浮盈=`(entry-peak_low)/entry`，达到启动阈值后保护线=`entry+(peak_low-entry)*lock`，只向下收紧；实际初始止损=`entry*(1+.005)`。
- 日线20/2、5分钟52/99、0.5%止损、65%锁利仍是固定设计；均值、波幅、保护价格和数量才是由行情/账户计算的结果。

## 默认不参与退出的经验公式

MA退出线、斜率风险、浮盈放松和动态黄金比例锁利分支默认关闭。动态曲线的端点与指数没有市场统计校准证据；公式确定不等于来源充分。见 `risk.py`、`profit_protection.py`。
