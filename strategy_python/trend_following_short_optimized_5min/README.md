**评估结论：通过本轮三个阶段的收益改进检验，但留出期回撤上升；可作为后续验证候选。**

2025-01-01 至 2026-09-01 留出期，500 USDT 独立起步：原版净收益 56.27，新版 83.89 USDT；分钟收盘权益回撤 8.94% → 10.65%。该区间曾被原策略研究使用。

独立主类：`TrendFollowingShortOptimized5MinStrategy`。

选中 `extend_4pct`：移动止盈的启动门槛从 **2% 改为 4%**，峰值盈利锁定比例仍为 65%。假设是：弱势日线背景中的有效下跌常需要经历反弹，过早启动移动止盈会截断后续下跌收益。

完整 5 分钟 MA52 下穿 MA99，并通过原来的两条日线低点/BOLL 过滤后入场。前一日使用已收盘日线，当日使用截至当前信号时刻的动态日线，不读取未来收盘。

实际成交后立即挂 0.5% 原生止损；持有完整输入分钟后，浮盈峰值达到 4% 才锁定峰值盈利的 65%。原名义仓位 1 倍、最多一份持仓、关闭额外小时过滤及重新入场区域限制的配置均保留。
