# 第一轮筛选与复核规则

在读取开发回测结果前确定。smoke只是行为验证，不能按其中盈亏筛选。

1. 每种不同基线分别比较全部场景，完整保留失败。默认关闭新规则的main是基线。
2. 机制改善首选开发期净收益更高且最大回撤不高于基线；至少15笔且不少于基线交易数25%，以降低只剩极少交易造成的误判。不把它当统计显著性门槛。
3. 每基线最多选两个不同改进机制进入复核：优先上述同时改善者；按净收益差/500减回撤差的简单无量纲分数排序（回撤从百分数转成小数），同一机制的相邻参数只取一个代表，邻近值后续单列检验。不因为样本少就声称可靠。
4. 如果没有同时改善者，保留一项有明显风险控制或费用结构改善的诊断候选，标为未通过而非接受；下一轮寻找或组合有机制依据的点，不用降低仓位掩盖问题。
5. 入选者及基线都运行2024与2025—2026-08-30独立区间。跨期收益/回撤/费用/单位名义盈亏比/活跃性反转则拒绝通用改进结论；不能查看近期后反复更换参数到盈利为止。
6. 第二轮围绕可解释缺陷组合不同作用点，保留单独因素对照；进入「空」之前先判断固定预算机制是否改善。最多两个开发候选不是最终只优化两个策略，八位置范围不变。

备注：八位置中同源的TFL/TFS/PBS开发期共享实验减少重复，最终必须用对应独立包验证每位置实际选择。更优PnL以完整曲线、收益、回撤和活跃风险比较，不能只凭本排序分数宣称达成。

## 时间频率修订（尚无clock候选结果时）

变更信号周期本身会改变预期信号数量，故clock15/clock30的相对交易数下限乘5/信号分钟数；开发期绝对下限15、复核期绝对下限10保持。其他退出、费用、风险场景仍用原25%相对下限。修订时MRL首组已见结果，TFL main/time24在跑，所有clock场景尚无结果；此修订基于预期信号频率，不以收益选门槛。
