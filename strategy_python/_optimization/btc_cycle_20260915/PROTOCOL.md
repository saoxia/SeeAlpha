# BTC八策略「总—子—时—空」循环优化

## 原始目标与不变约束

用户要求优化最新机制BTC八策略，现有代码不改，优化后新建。必须实际完成总（收益率、回撤、胜率、盈亏比、PnL曲线诊断）、子（可检验假设及对照回测）、时（时间参数变化及跨时期复核）、空（杠杆、最大持仓与资金曲线）并循环改进，不用单纯降低仓位或不交易冒充成功。

当前最新机制只有5个不同配置。暂按原来的四家族×原/优化8个位置建立独立新包：MRL原位→2σ，MRL优化位→2.25σ；TFL/TFS/PBS两位置各自承接相同最新机制起点，必须明确基线重复，不能宣称8种不同基线。已向用户请求可选确认，收到纠正时调整映射。

原策略、机制系数、历史回测与生产入口只读。所有新增代码和研究产物限定在新目录/新包。启动前保存全量现有策略代码/配置文件哈希，结束检查未变。

## 评估原则

- 使用相同BTC分钟数据、手续费和合约步长；资金独立500 USDT。以连续2021-01-01至2026-08-30历史作最终曲线比较；2021—2023为开发、2024为选择复核、2025以后为历史审计。机制本身已用2021—2023训练，且后段历史均已查看，不假称盲样本外。
- 第一轮单因素、固定预算，记录所有候选与失败。不在复核收益上无限寻找单一最佳点。第二轮只围绕明确有证据的缺陷组合，再检查组合与单独因素差异。
- 「时」同时考察真实时间参数（持仓期限、均线记忆/信号频率、冷却期）和区间/年度稳定性，不靠挑起止日期掩盖亏损。
- 「空」区分账户保证金杠杆与实际名义暴露。必须实际重跑不同预算/名义上限，不能简单乘收益曲线。对无影响的保证金杠杆结果也如实记录。趋势最新代码只有单持仓快照，不能直接去掉限制启用多仓；最大持仓首先指名义金额上限，若增加独立腿须另做快照隔离与行为测试。
- 首选收益提高且回撤不恶化、费用/邻域结果不脆弱。同时观察年度盈利一致性、最坏交易、回撤持续时间、活跃月份、净单位名义收益、交易集中度。不能以零成交/长期无成交获得的低回撤判断优化成立。
- 若无候选跨时期改善，应继续回到总诊断寻找新机制缺陷；不得为宣称成功覆盖旧策略、隐去失败或伪造正收益。不承诺市场数据必然存在可盈利方案。

## 第一轮待检验假设（在新候选结果前声明）

1. MRL：小额均值回归目标配25%灾难止损形成极端负盈亏比；检验有限持仓期限、禁止深度加仓以及结构失败退出。止损收紧不自动放大定仓。常数风险作为已知对照，需解释长期不交易状态。
2. TFL：频繁信号和往返费用吞噬优势；检验较慢信号记忆/再入场冷却、最小入场ATR尺度对应的费用比，以及退出与持仓时限。不因止损变宽增加价格风险。
3. TFS：优势小且交易稀少；优先保护既有交易结构，检验锁利和持仓时限，避免把少数大盈利一刀切。
4. PBS：24h期限可能截断4R目标路径，均线回落信号缺乏结构趋势过滤；分别检查12/48h期限、2R/3R目标以及过去可见趋势背景。保持同预算后再调预算。
