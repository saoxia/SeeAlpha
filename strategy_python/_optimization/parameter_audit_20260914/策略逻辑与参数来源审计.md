## 1. 先回答“这些数值为什么是这些数值”

目前可以确认**数值怎样参与计算，以及本轮新数值如何胜出**；不能把缺失的原始研究过程补写成已经证实的统计规律。许多参数有可解释的经济含义，但确切取值仍是经验设定或回测筛选结果。

本次把两件事分开：

- **历史来源**：当初有没有样本、实验和选择记录？有就列出；没有就明确写“未找到”。
- **统计解释**：今天能提出什么可被数据否定的假设，来判断这个值是否有可迁移的依据？这属于待检验解释，不是追认其历史来源。

目前最明确的结论是：

| 对象 | 已有依据 | 尚不能声称 |
|---|---|---|
| MRL 布林带 2→2.25 | 有开发、验证候选筛选记录 | 2.25 是某个已估计尾概率或最优回归边界 |
| TFL 启动浮盈 2%→3% | 有候选比较；3%通过本轮门槛 | 趋势上涨普遍在3%以后才可靠 |
| TFS 启动浮盈 2%→4% | 3%和4%都有开发/验证改进，4%验证收益更高 | 4%是跨资产不变常数，或已排除过拟合 |
| PBS 小时20、4R、24小时 | 有既往结构搜索和邻近收益风险比记录 | 所有组成参数都经过统计估计 |
| MRL 312/120窗口、17%/83%仓位谷底、26+1.5d/1.8d | 公式可以从代码复现 | 已有显著性、分位数、回归拟合或跨市场证据 |
| 仓位、风险预算、成本缓冲 | 有明确的资金管理或模拟含义 | 都应当从收益最大化中“反推出最优值” |

## 3. 行情、指标与绩效数字分别怎样得到

### 行情和时间边界

上轮实验标的是 Binance ETHUSDT USDT本位永续；读取本地 Catalog 的1分钟K线，在策略内聚合5分钟、15分钟、小时、6小时和日线。输入、账户和预热定义见 [environment.py](../four_strategy_20260914/environment.py)，历史数据入口见 [research.py](../four_strategy_20260914/research.py)。管线配置见 [binance_sources.toml](../../../pipeline/binance_sources.toml)。本次没有重新下载或独立校验交易所原始成交档案。

预热天数分别为MRL 135、TFL 11、TFS 21、PBS 30；组合为135天。预热提供指标历史，不参与交易。这是指标就绪的工程安排，不是预测常数。所有日期按UTC、区间左闭右开。

上轮审计记录开发期缺584分钟、验证期15分钟、保留期19分钟。五分钟初筛丢弃不完整桶，和分钟级最终结果的成交路径不同。PBS/TFS日线背景有缺口重建/失效规则；MRL风险模型使用小时数量门槛，不能把其他包的严格连续性保证直接套给它。

### 指标公式

令当根已完成K线收盘为C、最高为H、最低为L：

| 指标 | 当前实现 | “公式已知”不代表什么 |
|---|---|---|
| SMA(n) | 最近n个收盘的算术平均 | 不代表n已从自相关或周期分析估计 |
| BOLL(n,k) | SMA±k×sqrt(Σ(C−SMA)²/n)，总体标准差 | 不代表价格正态分布，也不代表穿轨概率固定 |
| 均线交叉 | 快慢均线差从≤0变>0为金叉，从≥0变<0为死叉 | 同侧持续状态不是新交叉 |
| 小时MA斜率 | `(C_t−C_(t−20))/20 = MA_t−MA_(t−1)` | 多头比较斜率与6小时前斜率，不是简单要求斜率>0 |
| ATR14（PBS） | `TR=max(H−L,abs(H−上一收盘),abs(L−上一收盘))` 的14项算术平均 | 不是Wilder递推ATR；换实现会改变止损 |
| MRL不利状态比 | 近54根15分钟K线中 `L<当根MA99` 的次数/54 | 不是收益率均值、下跌幅度或独立样本概率 |
| MRL强度 | 近期方向最大跌幅/过去参考窗口中的方向最大跌幅 | 最大值归一化不是百分位排名 |
| 浮盈启动值 | 相对实际入场价的有利价格变化比例 | 不乘杠杆，不扣手续费，不是账户收益率 |

尤其不能用“2σ约有某种正态覆盖率”解释这里的入场胜率：分布、窗口内依赖、低点而非收盘的触及、限价成交以及其他过滤条件都会改变事件概率。

### 收益、回撤与成交成本

每个独立账户500 USDT，账户保证金杠杆5倍；实际名义仓位由策略另算。净收益来自引擎账户并与成交现金流核对。分钟权益=现金流余额+有符号净数量×当分钟收盘价；回撤=1−权益/此前权益峰值。手续费模拟maker 2bp、taker 5bp，历史资金费率未重放。额外2/5/10bp压力是从既有成交额扣费，不会重跑订单和仓位。

盈亏比采用平均盈利交易/平均亏损交易绝对值，不是利润因子。MRL必须将加减仓归入完整持仓周期；其持仓报表盈亏与账户有小额差异，上轮补充审计改用按持仓编号聚合的成交现金流。详见 [TRADE_METRICS.md](../four_strategy_20260914/TRADE_METRICS.md)。

## 4. MRL原/新版：逻辑与每组参数

### 实际交易流程

1. 5分钟BOLL就绪，交易开始时间已到，且不在冷却/硬止损恢复等待中。
2. 最近54个有效15分钟状态中，低点低于MA99的比例不超过65%。整数上等价于最多35次；36/54已大于65%。
3. 按最新5分钟下轨挂首仓买入限价单：原版SMA20−2σ，新版SMA20−2.25σ。生成挂单不等于成交。
4. 依据方向风险、价格区间位置、恢复系数和预定四层满仓止损损失计算每层数量。
5. 首次成交后48小时内可加仓，最多4个等数量单元。后续价位按**届时均价**分别下移0.5%、1%、2%。不是每次相对首仓价格。
6. 持仓超过2单元时，在均价处挂半仓退出；降到≤2单元后，在均价上方0.5%挂全平。均价退出未扣手续费，并非净收益保本。
7. 硬止损随当前均价计算为均价×0.75。硬止损后等待完整6小时K线低点≥其MA52才解除等待；日线MA52另控制恢复确认。普通止盈全平后冷却5分钟。

源码：[features.py](../../mean_reversion_long_5min/features.py)、[signal.py](../../mean_reversion_long_5min/signal.py)、[strategy.py](../../mean_reversion_long_5min/strategy.py)、[execution.py](../../mean_reversion_long_5min/execution.py)。

### 周期、阈值、仓位的来源

| 参数组 | 数值及时间含义 | 能解释的作用 | 现有来源/不足 |
|---|---|---|---|
| BOLL | 20×5分钟=100分钟；k原2、新2.25 | 要求价格相对近期均值更低 | 原值来自交接；新版有筛选证据；没有“回归边界=2.25”的估计 |
| 趋势过滤 | MA99×15分钟=24小时45分；54次=13小时30分；65% | 避免大多数近期K线处于均线下方时继续抄底 | 继承交接；未找到窗口/比例的原始样本研究 |
| 止盈/加仓 | 0.5%止盈；4层；0.5/1/2%加仓距；48小时加仓窗口 | 小回归获利，随下跌追加风险 | 缺少条件回归时间/幅度分布依据；48小时不强制平仓 |
| 周期风险 | 25%价格止损；30%基础权益风险 | 按最坏计划四层损失反推数量 | 风险设计，不是止损25%保证最多亏权益25% |
| 方向参考 | 312小时=13天；120天参考 | 用较长期历史最大跌幅给近期跌幅归一化 | 没有证据证明13天或120天为特定市场周期 |
| 恢复 | 6小时和日线MA52；快照26根6小时线 | 前者参与恢复；快照只记录 | 52原始依据未找到；当前26根快照不参与决策 |
| 额外恢复风险 | d≥7天；窗口[26+1.5d,26+1.8d]；系数0.30 | 在特定止损后时段减少新周期预算 | 找不到该仿射窗口来自事件统计或回归的记录 |
| 定仓成本 | 2bp入场、5bp强退、再乘1.05 | 让计划数量预留成本 | 成本假设，不替代引擎扣费；5%是风险金额缓冲，不是价格滑点5% |

### 容易漏掉的代码内参数

这些值位于 [risk.py](../../mean_reversion_long_5min/risk.py)，不是只读config就能看到：

| 常数/曲线 | 精确规则 | 审计判断 |
|---|---|---|
| 强度曲线结点 `(强度,系数)` | `(0,.75),(.55,.75),(.62,.80),(.80,.90),(1,1.05),(1.2,1.2),(1.4,1.3)`；端点外截断 | 手工指定映射；没有结点拟合依据 |
| 结点间平滑 | `s=u²(3−2u)`，在相邻结点值间插值 | 保证平滑的数学构造；平滑本身不证明预测有效 |
| 区间位置 | `z=(P−近312小时最低)/(最高−最低)`，包含当前价 | 可复现的价格位置，不是历史出现频率 |
| 位置风险曲线 | 17%和83%处系数最低0.10；34%～66%处为1；边缘0/100%又升回1，分段二次连接 | **并非越靠极端越减仓**；双谷形状和拐点最需单独证明 |
| 计划加仓 | 第2/3/4层相对此前均价−0.5/1/2% | 预设网格，不是从价差分位数生成 |
| 部分退出 | 超过2单元先减半 | 结构设计；不是2次失败具有统计显著性的证据 |

此外，当前初始化强制`max_units=4`，并不能只改配置就测试3层或5层；那需要同步修改风险/加仓实现，属于新策略研究。风险历史就绪条件允许比窗口目标少2根小时线，预算复核另有0.01 USDT数值容差；这些是实现容差，不是市场信号阈值。

例如首仓100、每层数量相等，计划四层价格为100、99.5、98.7525、97.42915，满层均价98.9204125，计划硬止损74.190309375。实际限价成交/部分成交可能不同，因此执行时仍检查新增仓位是否超过已定周期预算。

设E为当前权益、q为每层数量、p_i为计划价格、p̄为满层均价、S=.75p̄，则：

`R = E × .30 × 强度系数 × 位置系数 × 恢复系数`

`q = 向下取整至数量步长 { R / [(4×abs(p̄−S) + Σp_i×.0002 + 4S×.0005)×1.05] }`

故30%只是基础系数；强度系数最高1.30，若其他系数为1，计划比例可达39%。这是源码中的预算上限关系，不是实际损失保证。实际缺口、成交差异等仍会影响损失。

**如何反推合理性：** 若要说明“为什么在17%/83%减仓”，应先按z分箱统计未来完整周期损失与尾部损失，观察是否真的有两个风险峰；再检验风险峰的位置能否在不同年份复现。若分布单调或峰值不稳定，当前双谷形状就没有得到支持。不能只从这条曲线计算后的盈利结果反推它正确。

恢复窗口同理：以每次硬止损为事件，记录释放等待d、止损后天数τ、日线恢复情况和后续损失。只有风险在`26+1.5d≤τ≤26+1.8d`内可重复升高，才能支持这个窗口。几个硬止损事件不足以支持多个精细系数。

## 5. TFL原/新版：逻辑与参数

完整小时收盘高于小时MA20；本小时MA斜率高于6小时前斜率；本小时MA变化率严格大于−0.1%。同时出现5分钟MA52上穿MA99，当根才市价买入。过滤不通过就跳过该交叉。

每笔名义金额为权益1倍，默认最多1份。实际成交均价P挂0.5%止损。完整持有的分钟更新有利峰值，跳过入场分钟极值；达到启动值a后按65%锁利，保护线只向有利方向移动。原a=2%，新a=3%。新保护不回溯触发；收盘已越线时按当前市价退出。全平后须观察价格回到5分钟MA20±0.2σ才重新获得入场资格，还必须等新的有效金叉。

若峰值相对入场浮盈为m，则锁利线为`P×(1+.65m)`；初始止损为`.995P`。恰好达到2%或3%时，理论毛保护位置分别为+1.30%、+1.95%。这是**由锁利公式推出的机械数值**，不是已经实现的净盈利，亦非3%合理性的统计证明。

| 参数 | 时间/意义 | 为什么目前是这个值 |
|---|---|---|
| 快52、慢99 | 5分钟窗口分别4小时20分、8小时15分 | 继承原版；本轮仅对快线26/65做有限比较，不能证明52/99最优 |
| 小时20、斜率比较6、逆向上限0.001 | 20小时价格背景、6小时斜率变化、−0.1%容忍 | 缺少原始估计记录；这是趋势状态假设 |
| 启动原2%/新3% | 等待更大的有利移动才收紧止损 | 3%通过开发和验证；不是已估计行情分位点 |
| 锁利65% | 允许峰值毛利润回吐35% | 继承；50%/80%实验未取代；65不是胜率 |
| 初始止损0.5% | 控制单次不利价格移动 | 本轮固定，缺少最大不利变动分布依据 |
| 重入0.2σ | 平仓后要求回到均线邻域 | 继承；需要证明减少的假交叉成本大于错失趋势的代价 |
| 名义1倍、最多1份 | 资金管理限制 | 预算选择，不代表用了账户5倍杠杆 |

**为何3%胜出：** 原生开发收益−56.34→92.01，2024验证91.96→111.72。4%虽然开发112.45更高，但验证仅64.02；3%配套固定65%锁利通过本轮全部门槛。数据支持的是“这一候选在本轮选择中更好”，没有展示2.7%、3.1%等邻近值的稳定平台。

**待验证解释：** 2%启动可能过早截断上行路径；但延迟到3%也会让部分已盈利头寸重新亏损。需要在共同入场事件上重放退出规则，估计到达a的概率、到达后的继续上涨与回吐比例、最终扣费净收益。旧版在2%附近退出后，其交易记录不再包含后续峰值，因此不能只用旧版已平仓交易的MFE分位数“推导”3%；必须继续观察统一价格路径，并另外完整重跑策略检查占仓造成的后续信号差异。

源码：[indicators.py](../../trend_following_long_5min/indicators.py)、[strategy.py](../../trend_following_long_5min/strategy.py)、[state.py](../../trend_following_long_5min/state.py)。

## 6. TFS原/新版：不是多头条件的镜像

默认取消小时价格、小时斜率、逆向小时涨幅及重入区过滤。5分钟MA52下穿MA99后，还必须满足：

1. 前一根完整日线最低价低于该日BOLL(20,2)下轨；
2. 当天截至信号时刻的最低价低于**当时动态计算**的日线BOLL下轨。

动态日线用截至此刻的最新价格充当当日收盘，绝不能使用未来日收盘。条件不锁存；早先满足不等于后来仍满足。不完整日线会影响窗口就绪。默认不是“只用日线信号”，仍需新死叉。

每笔权益1倍名义金额、最多1份，初始止损`1.005P`。原版2%、新版4%毛浮盈启动65%锁利；保护线为`P×(1−.65m)`，新4%启动时理论锁住2.6%毛利润。全平无需回到MA20附近。小时方向过滤虽关闭，当前实现仍要求小时模型就绪；不能称为完全没有小时数据依赖。

**来源：** MA52/99、日线20/2、初始0.5%、固定65%继承原版。README记录过取消第2/3/4/7条条件，但当前可见研究目录没有完整的原始消融选优记录。因此结构简化也有历史选择自由度，不能只把本轮4%算进调参次数。

**为何4%胜出：** 原生开发/验证：2%为−10.79/44.40；3%为7.80/55.66；4%为52.59/77.59；4%配80%锁利为40.64/68.59。几个候选共同支持“延后启动、保留较长跌幅”的方向，最终固定65%锁利的4%验证收益最高。验证只有34笔，交易间还可能属于相同下跌行情，不能把34等同于34个独立市场事件。

**待验证解释：** 两日日线破下轨可能筛出持续下行环境，使更晚启动保护有意义。须分别检验两日日线条件、死叉条件及两者交互；按信号前波动率标准化最大有利/不利变动，检查4%相当于多少倍正常波幅。若BTC的4%属于罕见尾部而SOL常见，同一个百分比并不代表同样的事件强度。

源码：[strategy.py](../../trend_following_short_5min/strategy.py)、[indicators.py](../../trend_following_short_5min/indicators.py)、[README](../../trend_following_short_5min/README.md)。

## 7. PBS原/新版：结构止损与4R来自哪里

只用最近一根完整日线：低点破BOLL(20,2)下轨且收盘低于中轨。上一小时收盘≥上一小时SMA20，本小时收盘<本小时SMA20时，认为反弹失败，市价做空。

结构止损为最近12根完整小时最高价+0.25×ATR14；距离信号收盘必须介于0.4%与3%。止损按最小价格步长向下取整；实际成交价为P后，止盈为`P−4(S−P)`。满24小时在下一条行情事件市价退出；保护单异常另有退出处理。无加仓、无移动止损。

数量公式（舍入至合约数量步长）：

`q = floor_step(min(E×r / [(S−P)+(P+S)×.0007], E×名义上限/P))`

原独立类r=.005、名义上限1；上轮比较两边r=.015、上限3。

实现还限制单笔计划风险不得超过5%、名义上限不得超过5倍。这些是可接受配置的工程边界，并非统计得到的收益最优区间。

| 参数 | 来源 | 统计解释的边界 |
|---|---|---|
| 小时入场、SMA20 | 原搜索比较5分钟/小时、MA20/99等结构 | 有候选证据，不等于从周期谱估计出20小时 |
| 日线20、2σ、低点破轨且收盘弱 | 原候选中的crisis背景；20/2固定 | 选中背景不能证明内部20和2分别最优 |
| 12小时结构、ATR14、.25ATR | 原筛选固定；本轮结构6/24没胜出 | 未找到噪声越界分位数推导 |
| 止损范围.004～.03 | 原筛选固定风险门槛 | 未展示区间内外收益/成本的校准曲线 |
| 4R | 原候选1.5/2.5/4/6R选择；同结构2.5/6R亦盈利 | 支持一定邻域稳健性，不证明精确4最优 |
| 24小时 | 原比较24/72并偏好较短暴露；本轮12/36/48未胜出 | 有风险偏好成分，不全是统计最大化 |
| .0007成本缓冲 | 原筛选风险数量设计 | 不替代真实手续费与滑点 |
| 风险.015/上限3 | 原组合覆盖与既往3倍仓位实验 | 仓位预算改变，不是新Alpha |

原研究共294个组合：36个早期失败、162个慢周期失败、96个均线反弹失败结构。这些历史搜索都属于选择过程。来源：[原研究说明](../../_report/analysis/pullback_short_20260913/结果说明.md)、[冻结选择](../../_report/analysis/pullback_short_20260913/selection.json)、[第三轮筛选源码](../../_report/analysis/pullback_short_20260913/screen_failure.py)。

若仅有−1R止损和+4R止盈、无成本，盈亏平衡胜率为20%；当前有24小时时间退出及手续费，实际盈亏比也不是4。不能用“胜率超过20%”单独证明其有效。应统计止损、止盈、时间退出各自概率与平均净收益，并分别按市场阶段检验。

## 8. 本轮选参链条及过拟合边界

选择过程来自 [PROTOCOL](../four_strategy_20260914/PROTOCOL.md)、[research.py](../four_strategy_20260914/research.py)、[select.py](../four_strategy_20260914/select.py)，不是从最终全历史收益倒推：

1. 开发2021–2023、验证2024；2025–2026年8月本轮留作冻结后评估，但原项目此前已经使用过。
2. 每家族10个首轮候选（含基线）+2个后续组合，共48个五分钟开发配置。
3. 首轮按开发净收益挑3个非基线候选（至少20笔），加基线和第二轮最好组合；总20个配置做分钟级开发/验证。
4. 同时要求开发及验证净收益超过原版；验证回撤至多比原版高5个百分点；开发至少两个年度较原版改善超过.01 USDT；开发至少20笔、验证至少5笔。
5. 从全部通过者中选择验证净收益最高者；无人通过则保留基线。

回撤容忍5个百分点、笔数20/5、年度2年、改善.01等，是**选择器自己的人工门槛**，不是显著性检验阈值。验证用于择优，因而也是选参数据；48个配置之外，原策略的历次修改同样可能带来选择偏差，不能把48当整个项目总尝试数。

| 家族 | 冻结后本轮历史保留期净收益：原→新 | 允许得出的结论 |
|---|---:|---|
| MRL | 52.74→7.90 | 新k的开发/验证优势没有保持；有不稳定迹象 |
| TFL | 90.19→−30.45 | 3%启动的优势没有保持，收益符号也改变 |

| PBS | 126.62→126.62 | 保留同一规则与预算，没有新版改进证据 |

这些结果不能区分过拟合、市场状态变化、样本随机性及它们的组合。本次没有计算“过拟合概率”，也没有完成参数稳定性置信区间。全历史收益提升和单一留出段获利都不足以排除过拟合。来源：[最终结果](../four_strategy_20260914/RESULTS.md)。

## 9. 把“试出来的数值”转为可迁移的统计命题

下面是本次为各类参数建立的可检验解释，**尚未执行这些新估计**。其中任何新数值若由这些分析产生，都应算下一轮开发，不能宣称已被同一数据验证。

| 要解释的值 | 先采什么样本 | 要估计什么 | 什么结果会否定解释 |
|---|---|---|---|
| MRL k=2.25 | 所有其他条件通过的共同挂单机会，包括未成交者 | 各折价层触及/成交概率、净回归收益、到达时间、尾部损失 | 只减少成交却未提高条件净期望；年度方向不一致 |
| MA99、54、65% | 按不利状态比及市场阶段分箱的共同机会 | 过滤前后收益和尾部风险曲线，整数计数边界稳定性 | 35/54附近没有稳定变化，邻近阈值效果任意翻转 |

| MA52/99、小时斜率条件 | 所有交叉事件及无该过滤的对照 | 未来延续净收益、假信号率、过滤机会成本 | 增益只来自某一个牛/熊阶段或某一精确窗口 |
| 0.5%止损 | 共同入场后的统一观察路径 | 最大不利变动MAE分布、止损后的再入场成本 | 阈值落在正常噪声中央，扣费后反复损失 |
| 3/4%启动、65%锁利 | 共同入场路径+完整策略重放 | MFE、启动概率、启动后回吐比例、净收益及占仓机会成本 | 只有单一启动点突出，或去掉最大盈利行情后优势消失 |
| 两日日线BOLL条件 | 两条件分别及联合成立/不成立的信号 | 延续概率、条件交互效应、低波/高波分层 | 联合条件不比简单条件更稳，或样本过少 |
| PBS结构12/ATR14/.25/止损范围 | 所有反弹失败机会及被距离规则拒绝者 | 越过结构高点的噪声幅度、止损距离与净收益关系 | 被拒绝样本更好、ATR标准化后仍无稳定规律 |
| PBS4R/24小时 | 各共同入场的首次到达及未退出路径 | 各类退出概率、条件继续持有净价值 | 只在4R单点盈利；晚平好处无法抵偿尾部和成本 |
| 仓位比例/资金缓冲 | 账户风险容忍度和实际成交成本记录 | 达成风险目标的数量、尾部损失和成本误差 | 预算与实际损失长期偏离；这类值不必追求收益最优 |

MAE/MFE分别为观察期内最大不利/有利价格变动。观察期、取价方式、信号后何时可成交，必须事先统一。指标穿轨率、胜率和策略净收益是不同对象，不能互换。

统计单位优先采用完整加仓周期、完整交易事件或按日/周形成的时间块；重叠K线和同一趋势内的交易不是独立样本。应使用保留时序依赖的分块重采样给出区间，并做去除最大盈利事件、年度分层和成本敏感性。这里指定方法原则，没有声称任何置信区间已经通过。

## 10. 后续BTC/SOL验证应保留的两个不同问题

**直接迁移检验：** 冻结当前八版的信号参数和风险预算，替换标的、合约步长/最小量和实际成本，在BTC/SOL跑同样逻辑。它回答“ETH上得到的规则是否可直接迁移”。亏损不能随后调好再叫原规则验证成功。

**统计规则迁移检验：** 若先在开发数据建立诸如“启动值=信号前波动率的某个倍数”或“回归阈值由预先指定分位点决定”的公式，固定估计窗口、目标、更新频率和倍数，再在独立时间评估。它回答“同一估计方法能否迁移”，属于新版本研究，不是这八版的原样复核。

价格百分比虽已去掉币价单位，仍未消除不同资产波动率差异。BOLL倍数和ATR倍数更接近波动归一化，但也不保证条件概率相同。风险预算原则上保持一致，手续费、步长和最小订单量则服从目标市场实际规则。资产的可用历史、上市日期及预热必须检查；当前配置提到BTC不等于BTC数据已经完备，也不能假定SOL有2021年起的完整本地数据。

当前独立入口和本轮研究环境固定ETH标识，后续不能只改显示名称。需同步替换行情、InstrumentId、BarType、合约定义和仓位精度，且保留各策略日线时序语义。BTC/SOL与ETH同期也可能共同经历市场冲击，跨资产证据不能替代未来时间证据。
