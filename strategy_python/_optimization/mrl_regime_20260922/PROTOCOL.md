# 均值回归多头：日线趋势过滤与有限持仓周期

本轮为用户要求继续优化而新增的独立研究。已有历史均已参与研发，不能作为盲测或独立样本外证据；不更改四策略默认入口、原研究结果或正在运行的90天前向观察。

## 先固定机制与对照

对象为现行BTC均值回归多头的单层、7.5%计划风险预算版本。独立复制领域模块，关闭全部新增开关时须复现原BTC/ETH基线交易。初始500 USDT、5倍账户杠杆、135天预热、1分钟输入，连续账户不在年度边界重置。

1. baseline：全部新增开关关闭。
2. regime：首仓仅在最近完整UTC日线收盘高于52日日线均值、且该均值高于7个完整日之前的值时允许。52沿用原策略已有日线恢复尺度，7用于固定一周方向；均为待检验经验假设，不是拟合最优值。日线中断清空新增过滤历史，59个连续完整日重新预热；日线状态超过一天不继续使用。当天未收盘行情不进入过滤。
3. bounded：保留原入场，启用原策略已实现的24小时期限退出、两倍入场布林下轨至中轨距离的分钟收盘退出；退出后等待五分钟收盘回到中轨才重新准入。三个条件作为一个退出/重入规则组，不能将效果归因于单个参数。
4. combined：regime与bounded合用，为预先指定的主候选。

止盈、MA99过滤、定仓公式、资金预算、交易所约束及原25%保护止损保持不变；不会因为新增退出更近而扩大仓位。时间退出和布林距离退出均为分钟收盘触发的市价退出，不能保证亏损或持有时长硬上限，跳空和数据缺口仍可能越过阈值。单层避免加仓重置首仓时间的问题。

在同一边界沿用原数据更新顺序：先处理五分钟信号，再更新该边界刚闭合的日线；新增过滤因此不会使用尚未更新的当日日线。过滤只决定新首仓，不强制关闭已有持仓。

## 正式运行

固定BTC、ETH两个市场，四组规则，每次成交额外0或5bp两档手续费，合计16次原生引擎回放。费用通过合约手续费实际重跑，影响后续权益与数量；两市场使用同一组规则，不分别调参。

统一UTC [2021-01-01, 2026-08-31)，末日不含，实际截至8月30日。所有正式结果保留，不因中间盈亏追加网格或删除失败版本。运行前记录源码、方案、数据、参考结果和环境哈希及源码归档。

原费率baseline应逐笔复现已有BTC/ETH归因研究，BTC额外5bp基线另与已有多头压力研究对齐。基线若不一致先调查实现，不把不一致当优化收益。

## 判断

主候选combined在两个市场、两档费用下均须：全期和2025年以来连续账户净收益>0；完整交易至少100笔、近期至少30笔；分钟盯市最大回撤不高于相同市场/费用baseline；订单数量与委托金额合规、现金流对账通过。全部满足才记为“值得独立前向验证”。其他组用于机制消融，不按最高收益更换预先指定主候选。

全部披露收益、回撤、交易数、费用、持仓时间、最差5笔、去掉最好5笔、年度与近期表现、订单异常及缺失数据。即使净收益改善但仍亏损，也只称减少亏损，不称盈利策略。

本轮没有历史资金费率、真实排队、盘口滑点或逐日合约规则，只使用当前本地合约快照。5bp压力是成本代理，不能覆盖全部执行风险。通过仍需新的独立时间验证；失败则保留失败结果，不继续移动参数找最高点。
