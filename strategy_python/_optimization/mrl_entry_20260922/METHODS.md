# 方法选择与依据

## 项目证据决定先优化什么

上一轮日线过滤与收紧退出的16组回放没有产生通过版本。组合BTC/ETH在费用之前都已亏损；因此只降低手续费或改变止损不能被视为已经解决入场优势问题。详见[上一轮结果](../mrl_regime_20260922/INTERPRETATION.md)。

本轮落地成本空间准入及跌破收复确认，以固定退出/定仓机制进行两级对照。成本门槛避免用很小的预期价格移动承担相近的交易摩擦；确认假设检验下轨触碰之后出现收复时，后续回踩是否更有利。两者都只是可检验假设，不能在运行前称为有效。

## 原始资料

- [John Bollinger原作者规则](https://www.bollingerbands.com/bollinger-band-rules)：轨道触碰本身不构成独立买卖信号，趋势行情可持续沿轨运行。该说明支持额外检验价格确认，不直接提供本轮两根K线规则，也不证明回踩交易有效。
- [NautilusTrader官方成交模型](https://nautilustrader.io/docs/latest/concepts/backtesting/fill-models/)：历史数据不能完整还原模拟订单的市场互动，限价触价资格和不利滑点需要明确建模。实际调用以本项目安装的Python/Cython实现为准，冻结其环境；严格成交检查另行保存。
- [Bailey等，The Probability of Backtest Overfitting](https://www.davidhbailey.com/dhbpapers/backtest-prob.pdf)：重复尝试与事后择优会使历史绩效过于乐观。本轮限定两个新规则组合、同参数跨市场复核，保留失败；这种约束不能消除已有历史选择偏差。

检索日期：2026-09-22。这里只引用方法与限制，未导入他人的交易参数或收益结论。

## 暂不采用的方法

| 方法 | 本轮处理原因 |
|---|---|
| 继续扩大日线过滤和止损网格 | 之前已有明确失败结果，缺少新的机制依据 |
| 提高杠杆或仓位 | 无法把负的单位交易期望变为正值 |
| 复杂机器学习筛选 | 当前独立信息量与已见历史不足以支撑更大的模型选择空间 |
| 仅按历史最高收益选择市场或退出期限 | 会混入事后选择，无法回答跨市场可迁移性 |
| 成本空间准入 | 本轮cost对照，参数作为预算假设预先固定 |
| 跌破后收复再回踩 | 本轮reclaim主候选，加原生报价过期及严格成交复核 |
