# 参数机制研究与跨资产验证

目标：以可检验的信号后条件分布替代单一BTC/ETH波动比例，生成有统计定义的参数方案，实际实施并与ETH原方案、BTC固定及波动比例方案比较。不能保证发现历史参数的唯一真实成因；区分统计支持、未支持、样本不足与风险偏好。

## 冻结研究口径

- 资产ETH、BTC；使用本地相同分钟行情。2020仅预热，2021—2023估计，2024稳定性检验，2025—2026-08-30最终历史复核。
- 未来路径仅作为研究标签，不进入信号或实盘特征。跨分割边界的标签剔除；缺失/不完整未来路径剔除，不填造价格。
- 使用不受原持仓和退出截断的信号机会样本，单独说明其与真实成交的区别；完整原生引擎回测负责检验持仓互斥、费用、订单步长和定仓影响。
- 趋势研究相同均线交叉及背景信号后的6/24/48小时路径；24小时为主观察窗口，6/48小时检查结论依赖性。24小时是研究设计，不假称原趋势策略有24小时强退。
- MRL研究可见下轨的后续触及事件及48小时路径，同时观察6/24小时。触及后收益标签从下一完整分钟开始，避免使用成交前的同分钟极值。
- PBS研究均线回落及日线背景满足的小时信号，包括被旧止损范围排除的机会，检验结构高点、ATR缓冲和24小时退出逻辑。
- MAE/MFE、终点收益、恢复时间及达到目标前逆向幅度都来自公共未截断行情路径。不能只保留最终盈利样本来声称止损优越；盈利路径条件统计必须与损失样本及真实回测共同检验。
- 不把重叠事件当独立样本。汇报年份、月份覆盖，并采用按时间块的稳定性分析；精细尾部或稀少止损事件不强行拟合。
- 所有新增分位数、观察窗口或决策门槛明确作为设计选择；用少量预先声明的邻域检验，记录所有候选，不能用BTC全历史收益选参数再称迁移成功。
- Q1/Q2复杂风险曲线以常数预算为消融对照，检查条件尾部损失是否支持曲线形状。Q3恢复时间带必须先核对事件数量；证据不足保留未知结论。

## 必须交付（未完成前保持任务进行中）

1. 可复现ETH/BTC事件及完整路径数据、数据质量与无前视检查。
2. 参数假说、统计定义、证据与不确定性对应表；包含原ETH数值在新统计分布中的位置。
3. 用统一定义生成的ETH/BTC参数方案；保留所有旧版对照，说明改了哪些规则及为何。
4. 必要的行为测试、原生回测、年度/区间和成本比较；不把研究路径模拟当成最终回测。
5. 总结哪些未知参数获得支持、哪些没有支持；优化未成立时明确报告，避免事后编造“真实逻辑”。
