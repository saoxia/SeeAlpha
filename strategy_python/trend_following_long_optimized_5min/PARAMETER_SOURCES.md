# trend_following_long_optimized_5min 参数计算与来源

本页对应新版当前默认配置。源码中的计算逻辑和参数取值依据分开记录；有公式不等于精确系数有统计证据。

[统一来源规则与迁移说明](../PARAMETER_SOURCES.md) · [待讨论清单](../PARAMETER_QUESTIONS.md)

## 由行情和账户实际计算的量

- 5分钟快/慢SMA差跨过0触发入场：由收盘均值计算，首次就绪不产生交叉。52/99是窗口选择，尚非从周期分析估出的常数。
- 小时斜率`(C_t-C_(t-n))/n = MA_t-MA_(t-1)`；当前斜率与6小时前比较，并检查小时价格在MA20上方及单步MA变化率>-0.1%。计算公式已知，20/6/.001的精确取值仍是经验值。
- 每份数量：`floor_step(盯市权益*fraction/当前入场价)`，步长来自目标合约。fraction=1是资金预算，与账户保证金杠杆不同。
- 峰值毛浮盈为`(peak-entry)/entry`；达到启动阈值后保护线=`entry+(peak-entry)*lock`，只朝盈利方向移动。峰值来自完整持有分钟；不使用入场分钟未知先后顺序的极值。门槛与65%锁利是自由参数；保护价格是计算结果。
- 重入区为`abs(close-MA20)<=.2*σ`。σ为当前价格样本总体标准差；.2仍是经验倍数。

## 默认不参与退出的经验公式

斜率风险映射`clip(.5-favorable_slope/(2*scale),0,1)`及浮盈放松`1/(1+profit/scale)`默认关闭；不能从当前收益推断其有效。动态锁利函数的黄金比例指数、1.55%/3.5%启动区间端点和40%/95%锁利端点同样未校准，默认不使用。见 `risk.py`、`profit_protection.py`。
