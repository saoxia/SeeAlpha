# 趋势跟随做多：给趋势更多延续空间

[参数计算公式与来源](PARAMETER_SOURCES.md) · [缺乏校准依据的待讨论项](../PARAMETER_QUESTIONS.md)

**评估结论：研究版本：留出期亏损且回撤上升。暂不建议替换原版。**

2025-01-01 至 2026-09-01 留出期，500 USDT 独立起步：原版净收益 90.19，新版 -30.45 USDT；分钟收盘权益回撤 19.22% → 26.46%。该区间曾被原策略研究使用。

独立主类：`TrendFollowingLongOptimized5MinStrategy`。

选中 `extend_3pct`：移动止盈的启动门槛从 **2% 改为 3%**，峰值盈利锁定比例仍为 65%。假设是：过早锁利会在趋势尚未展开时退出；保留更多波动空间，有利于捕获后续上涨。

完整 5 分钟 MA52 上穿 MA99 且原小时趋势过滤通过后入场。实际成交后立即挂 0.5% 原生止损；持有完整输入分钟后，浮盈峰值达到 3% 才启动移动保护，锁定峰值浮盈的 65%，保护线只向有利方向移动，不回溯触发已过去的分钟。

每份名义金额仍为账户权益的 1 倍，最多一份持仓。小时 MA20、斜率变化过滤与平仓后的重新就绪条件保留。没有通过加大仓位或放宽初始止损提高收益。
