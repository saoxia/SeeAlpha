## 五类来源分别处理

1. **计算结果**：均线、总体标准差、BOLL价格、ATR、方向最大跌幅、实际成交均价、止损/止盈价格、数量。这些已有运行时公式，本次在公式位置补充来源说明。换标的后随输入行情、账户和合约步长计算，不应复制ETH的价格或数量。
2. **历史筛选值 `[筛选]`**：例如新版2.25σ、3%/4%启动值、PBS4R。保留可追溯候选记录；筛选胜出不代表统计定律，不自动替换为新估计器。
3. **经验规则 `[经验]`**：有可解释的方向假设，但窗口长度、阈值或曲线形状未找到校准依据。保留当前值，并进入[待讨论清单](PARAMETER_QUESTIONS.md)。
4. **风险/成本预算 `[预算]`**：例如30%周期基础预算、0.5%价格止损、手续费缓冲。应由可接受风险与实际成本约束决定；不能一概通过历史收益最大化选取。
5. **工程约定 `[工程]`**：合约、K线、预热交易边界、订单标签、记录快照等。有的是数据依赖，有的是运行设置，不需要为其编造Alpha解释。

这里的“统计定义”主要指SMA、总体标准差、滚动比例、极值和ATR的实际计算方法；它不意味着这些量对未来收益的预测能力已经经过统计检验。

## 能从数学约束推导的数字

有些代码系数可以找到严格来源，但这个来源是数学定义，而非行情拟合：

- MRL结点间插值`3u²−2u³`中的3和2：令三次多项式满足`s(0)=0、s(1)=1、s′(0)=0、s′(1)=0`，解出二次项系数3、三次项系数−2。这解释了为什么用这两个系数使结点平滑连接；不解释强度结点本身为何选0.55、0.62等值。
- 趋势斜率风险`0.5−x/(2a)`中的0.5和2：要求线性映射在`x=−a`时为1、`x=0`时为0.5、`x=a`时为0，再截断至[0,1]，即可得到该式。这解释中点和比例系数；a=.1及“线性关系适合市场”的假设仍未校准。
- EMA权重`2/(n+1)`是所用平滑定义，默认n=1得到权重1；不能反过来说市场数据证明n应当等于1。
- 动态锁利的增量.55来自上限.95减下限.40；浮盈区间归一化分母`.035−.0155`来自给定端点间距。端点和黄金比例指数仍是经验选择；当前分支关闭。
- 默认MRL比例门槛.65与54次状态联用，允许次数由整数约束得到`floor(.65×54)=35`；35是推导结果，不是又一个拟合参数。不能据此为.65和54补造统计依据。

这些推导与行情统计公式一起写入来源说明。可推导的系数不再只有一个孤立数字；不可推导的自由参数仍明确保留。

## 可计算结果与仍需选择的输入

| 输出 | 运行时来源/公式 | 仍需选择或核对的输入 |
|---|---|---|
| BOLL下轨 | `SMA(C,n) - k×sqrt(Σ(C-SMA)²/n)` | n、k、周期；不能把价格穿轨等同固定正态尾概率 |
| 均线交叉 | 当前快慢SMA差相对上一根跨过0 | 快慢窗口；首次初始化不视作交叉 |
| 小时斜率 | `(C_t-C_(t-n))/n`，与过去斜率比较 | n与比较窗口；变化率阈值 |
| 不利状态比 | 最近窗口内`low<当根MA`的次数/窗口数 | MA周期、比例窗口、准入比例 |
| ATR | `mean(max(H-L,abs(H-C_prev),abs(L-C_prev)), n)` | n；本项目PBS使用算术均值，不是Wilder递推 |
| 结构止损 | 结构窗口最高价+缓冲倍数×ATR | 窗口、缓冲倍数、允许距离范围 |
| PBS止盈 | `实际入场 - R×(结构止损-实际入场)` | R；时间退出使实际盈亏比不等于R |
| 峰值保护价格 | `实际入场+(有利峰值-实际入场)×锁利比例` | 启动门槛、锁利比例；均为毛价格收益口径 |
| 权益定仓 | `floor_step(权益×名义比例/价格)` | 名义比例、目标合约数量步长、当前权益 |
| 风险定仓 | `floor_step(风险预算/每单位含缓冲止损成本)`，再限名义金额 | 风险预算、止损规则、真实费用和数量步长 |
| MRL风险强度 | 近期方向最大跌幅/前移参考窗口最大方向跌幅 | 窗口与强度映射曲线；极值不是分位数 |
| MRL区间位置 | `(当前价-窗口最低)/(窗口最高-窗口最低)` | 窗口与位置风险曲线；位置不是出现概率 |

计算已有实现，本次没有将其改写为第二套算法，也没有增加会改变入场/退出行为的自适应阈值。表达`312=13×24`或`52=260÷5`只是在换单位，并不能证明13天或260分钟是合理统计尺度，因此没有用这种代数拆分充当“去掉经验参数”。

## 迁移到其他产品时的固定规则

- 首先固定当前八版逻辑，替换行情、InstrumentId、BarType、交易所合约定义、价格/数量步长和市场成本；独立入口目前默认ETH，不能只改展示名称。
- 用相同内部信号周期和UTC日线边界。TFS动态当日日线只用信号时刻已知数据；PBS只用最近完整日线。预热与缺口处理也属于实际策略的一部分。
- 百分比消除了币价单位，但没有消除波动率差异。4%在BTC和SOL可能代表不同强度；不得据此声称已经实现跨资产统计等价。
- 如需把固定百分比换成`信号前波动率×倍数`或滚动分位数，必须先明确：估计样本、回溯窗口、目标概率/损失、更新频率、最低样本数、历史不足与零波动时的处理。倍数/分位点仍是参数，不会凭公式消失。
- 新估计器只能读当时已知信息；后续路径只用于开发期校准。校准后的规则冻结，再用其他资产和后续时间验证。修改后应作为新实验记录，不能继续引用原冻结版本业绩作为新规则验证。
