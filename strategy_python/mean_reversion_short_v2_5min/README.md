# 五分钟均值回归做空 v2

独立 `MeanReversionShortV2Strategy`，ETHUSDT 永续，只做空；默认开仓名义杠杆上限 3 倍，
可设 3～5 倍。仅 UTC 周末建仓，五分钟收盘决定入场，小时线只用于背景过滤。
这是低频的五分钟信号策略，不是每五分钟交易一次。

## 默认逻辑

1. 仅当完整五分钟 K 线的收盘边界位于 UTC 周六/周日时允许建仓。
2. 最近完整小时收盘价 ≤ 小时 SMA20，且该 SMA20 ≤ 三根小时前的 SMA20。
   正在形成的小时线不参与过滤。小时数据缺失时旧过滤失效，重新预热连续窗口。
3. 当前完整五分钟最高价 ≥ 同期 SMA20＋3σ，且收盘价 < 开盘价。
   σ 为最近 20 根五分钟收盘价的总体标准差。包含上影线，但收盘确认前不交易。
4. 信号收盘价相对五分钟 SMA20 至少高 0.3%，保留回归空间。
5. 满足条件后市价做空。止盈限价为该信号时刻的五分钟 SMA20，入场后冻结，
   不随之后均线抬升而放宽目标。五分钟上下轨和均值都来自已完成 K 线。
6. 初始止损为信号收盘价＋4×五分钟 ATR14，ATR 使用真实波幅的算术平均。
   止损距离须在 0.4%～3% 之间，否则跳过。成交后立即挂仅减仓止损市价单。
7. 不加仓，最多一份持仓；止盈或止损后取消本策略另一保护单。
   入场满 12 小时，在下一条行情事件市价退出，离场可跨工作日，不等待回本。
   保护单取消/拒绝/修改失败时转市价清仓，未完成则下条行情重试。
8. 计划止损风险为账户权益的 2%。按止损距离及双边各 0.07% 成本缓冲反推数量，
   再受开仓名义金额上限限制。上限计算额外预留入场费用所需保证金，数量向下取整。

## 杠杆口径

`--max-leverage 3` 同时设置账户保证金杠杆为 3 倍，以及新仓名义金额最多为权益的 3 倍；
`--max-leverage 5` 对应 5 倍。风险定仓可能使实际仓位低于上限，不是每笔固定满仓。
开仓后的有效杠杆会随市价和权益变化；回测没有完整模拟交易所实际强平规则。
2% 是计划风险，跳空、滑点、交易中断和费用偏差可能使实际损失更大。
`fee_buffer` 只是定仓缓冲，实际手续费由回测合约定义扣除。

## 运行

```bash
.venv/bin/python -m strategy_python.mean_reversion_short_v2_5min.backtest \
  --start 2021-01-01 --end 2026-09-01 --max-leverage 3

.venv/bin/python -m strategy_python.mean_reversion_short_v2_5min.backtest \
  --start 2021-01-01 --end 2026-09-01 --max-leverage 5
```

500 USDT 初始资金，3 天预热，默认读取已有 1 分钟行情并内部聚合 5 分钟/小时。
支持 1s、1m、5m 输入以及公共 `--check-data` 选项；默认不联网补齐缺口。
时间为 UTC，结束时间不包含。完整参数在 `config.py`，Python 回测入口可覆盖风险等参数。

策略已在组合工厂注册为 `mean_reversion_short_v2_5min`；当前只支持 `risk.mode=none`，
没有接入组合共享风险预算。原有三策略清单和旧均值回归做空策略保持独立。
该类没有实盘恢复/对账入口；引擎停止后可能不投递末尾成交到策略，最终状态以账户、
订单、持仓报告为准，重新运行须用新实例或 reset。

## 实验与局限

[实验结果及 PnL 曲线](../_report/analysis/mean_reversion_short_v2_20260913/结果说明.md)记录原生回测、
年度盈亏、3/5 倍上限、分钟盯市权益回撤及成本压力。

普通布林、区间挂单、RSI、回归通道、浮盈保护等大量候选失败，历史结果全部保留。
最终周末限制由 2021–2023 训练和 2024 验证筛选而来。样本少、筛选次数多，存在明显选择偏差。
2025 年以后的行情曾用于淘汰早期候选，不能宣称它是整个研究过程严格未污染的样本外。
全历史为正不等于近期、每年或未来盈利；应同时查看最近区间的亏损。
历史资金费率尚未重放；分钟 OHLC 无法完全重建真实盘口、延迟和盘内成交顺序。
