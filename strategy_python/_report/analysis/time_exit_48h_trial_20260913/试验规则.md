# 48小时渐进亏损退出试验

本试验使用独立开关 time_gated_stop_trial=True，time_exit_loss_step=0.01，time_exit_max_loss=0.25。默认开关False保留原策略行为。

- 满48小时，允许价格相对持仓均价上涨1%；之后依次间隔1、2、3、4……天更新，每次按本次间隔天数增加相同百分点，第30天达到25%，之后保持25%。更新日为2、3、5、8、12、17……；第k次更新日=2+k×(k−1)/2。
- 目标退出价=当前持仓均价×(1+允许比例)。到期启用全仓买入限价退出，价格回到目标或更低时才成交。价格超出允许范围继续等待。
- 首仓/两份仓位取消即时30%硬止损，避免未满足时间条件先行强平；0.5份余仓原保护止损保留。
- 原P1/P2止盈在超时退出启用前继续有效。超时后取消加仓，不再拆分止盈。
- 计时起点：首仓首次成交；每次加仓实际成交重新计时，部分加仓每次成交也重置；减仓不重置。
- 仓位计算暂保留旧版30%参考止损的定仓方式，以比较退出规则。取消硬止损后，该参考值不再保证实际损失上限。
- 比例针对价格距离，不包括手续费，也不是账户收益率。保持已有回测费用口径。
- 回测结束时的清仓、执行异常应急处理是引擎/执行规则，应与正常限价退出区分检查。

旧版源文件和测试保存在rollback目录，原回测结果完整保留在相邻time_exit_step_trial_20260913目录。
