# pullback_short_1h 参数计算与来源

本页对应原版当前默认配置。源码中的计算逻辑和参数取值依据分开记录；有公式不等于精确系数有统计证据。

[统一来源规则与迁移说明](../PARAMETER_SOURCES.md) · [待讨论清单](../PARAMETER_QUESTIONS.md)

## 由行情和账户实际计算的量

- 最新完整日线BOLL下轨=`SMA20-2*总体标准差`。前一日low破轨且收盘在中轨下方；小时收盘由上往下穿过本小时SMA20时确认反弹失败。
- `TR=max(high-low,abs(high-previous_close),abs(low-previous_close))`；ATR=最近14项TR算术均值，不是Wilder递推。结构止损=`最近12根完整小时最高价+.25*ATR`。这些价格随标的更新；14/12/.25仍是窗口和缓冲假设。
- 止损距离=`结构止损/信号收盘-1`；0.4%～3%是准入风险界限，不是估计分位数。
- 以实际入场P和结构止损S计算止盈`P-4*(S-P)`；4为目标收益风险比，不等于实际盈亏比（还有时间退出、费用）。结构价格须按目标合约步长取整。
- 定仓：`floor_step(min(E*r/[(S-P)+(P+S)*fee_buffer], E*名义上限/P))`。E为盯市权益，费用缓冲是每单位入场和止损金额的成本假设；并不代替引擎实际扣费。
- 首次入场成交后24小时，在下一行情事件退出；时间阈值来自原候选选择及短暴露偏好。

## 原类与原组合要区分

原类单独运行r=.005、名义上限1；原组合覆盖为.015、3，新类也为.015、3。上轮比较两边都使用原组合预算。这里没有新的择时改善；仓位预算不是统计规律。

## 配置逐项来源

“经验”包括有经济假设但未找到精确值校准记录的规则；“预算”是风险偏好或成本假设；“筛选”只证明历史候选选择。

| 字段 | 默认值 | 类型 | 含义/计算方式 | 证据与局限 |
|---|---|---|---|---|
| `instrument_id` | `<required>` | 工程 | 交易合约标识；本轮ETHUSDT-PERP.BINANCE | 工程约定；不是由市场统计估计；运行设置 |
| `bar_type` | `<required>` | 工程 | 行情类型；本轮外部1分钟LAST K线 | 工程约定；不是由市场统计估计；运行设置 |
| `order_id_tag` | `PBS` | 工程 | 订单编号标签，用于隔离策略订单 | 工程约定；不是由市场统计估计；运行设置 |
| `trade_start_ns` | `0` | 工程 | 允许交易的UTC纳秒时间戳；工厂用回测开始时间覆盖0 | 工程约定；不是由市场统计估计；运行设置 |
| `ma_period` | `20` | 筛选 | 小时SMA收盘样本数 | 趋势默认原始依据未找到；PBS在MA20/MA99结构候选中选20；启用/部分间接 |
| `daily_boll_period` | `20` | 经验 | 日线BOLL收盘样本数20 | TFS继承；PBS固定背景设计，未证明20/2统计最优；日线过滤启用；TFS仅日线模式关闭 |
| `daily_boll_std` | `2.0` | 经验 | 日线BOLL总体标准差倍数2.0 | TFS继承；PBS固定背景设计，未证明20/2统计最优；日线过滤启用；TFS仅日线模式关闭 |
| `atr_period` | `14` | 经验 | 小时真实波幅算术均值样本数14 | 原研究中14/12/0.25固定；本轮结构6/24未选中；启用 |
| `swing_period` | `12` | 经验 | 小时结构最高价窗口12根 | 原研究中14/12/0.25固定；本轮结构6/24未选中；启用 |
| `reward_risk` | `4.0` | 筛选 | PBS止盈目标=实际入场价-4×实际结构风险 | 原294次结构筛选中的4R；邻近2.5R/6R也盈利；本轮保留；启用 |
| `max_holding_hours` | `24` | 筛选 | 首笔成交后小时数，下一行情事件市价退出 | MRL48小时继承；PBS24小时来自既往候选筛选并偏好较短暴露；启用 |
| `risk_fraction` | `0.005` | 预算 | PBS单笔计划风险/权益：旧类0.005，旧组合和新类0.015 | 旧组合覆盖；既往3倍仓位对照；不是本轮Alpha改进；启用 |
| `max_notional_fraction` | `1.0` | 预算 | PBS名义金额/权益上限：旧类1，旧组合和新类3 | 旧组合覆盖；既往3倍仓位对照；不是本轮Alpha改进；启用 |
| `min_stop_fraction` | `0.004` | 预算 | 结构止损距信号收盘的比例下限0.004 | 原研究固定风控门槛；未找到这两值的拟合记录；启用 |
| `max_stop_fraction` | `0.03` | 预算 | 结构止损距信号收盘的比例上限0.03 | 原研究固定风控门槛；未找到这两值的拟合记录；启用 |
| `stop_atr_buffer` | `0.25` | 经验 | 结构最高价上方额外0.25×ATR | 原研究中14/12/0.25固定；本轮结构6/24未选中；启用 |
| `fee_buffer` | `0.0007` | 预算 | PBS每单位风险加(入场价+止损价)×0.0007 | 定仓成本缓冲；不是实际手续费扣款；启用 |
| `close_positions_on_stop` | `True` | 工程 | 策略停止时清仓开关；不是持仓时长阈值 | 工程约定；不是由市场统计估计；运行设置 |
