# 下跌趋势中的反弹做空

[参数计算公式与来源](PARAMETER_SOURCES.md) · [缺乏校准依据的待讨论项](../PARAMETER_QUESTIONS.md)

独立策略 `PullbackShort1hStrategy`，固定只做空 Binance ETHUSDT 永续。
默认读取已有 1 分钟行情，内部聚合 UTC 完整日线和小时线。
没有加仓；最多一份仓位。核心目标是等待弱势行情中的反弹失败。

## 交易规则

1. **日线背景**：最近一根完整日线最低价严格低于该日 BOLL(20,2) 下轨，
   且收盘价低于中轨。BOLL 使用日收盘 SMA 和总体标准差。当日只使用最近收盘日线，
   不使用正在形成的日线或未来日收盘。该条件表示弱势背景，不要求长期均线持续下降。
2. **反弹失败**：上一根完整小时收盘价不低于其 SMA20，本根完整小时收盘价跌到
   当前 SMA20 下方。在小时收盘确认后市价做空，不根据该小时的高低价回溯成交。
3. **结构止损**：最近 12 根完整小时最高价 + 0.25 × ATR14。ATR 是 14 根真实波幅的
   算术均值。止损距信号收盘须在 0.4%～3% 之间；不符合则跳过。止损价按最小价格
   步长向下取整，入场实际成交后立即挂仅减仓的买入止损市价单。
4. **止盈**：实际成交均价 − 4 ×（结构止损 − 实际成交均价），挂仅减仓买入限价单。
   不移动止损，不逆势补仓。止损或止盈成交后取消本策略另一保护单。
5. **时间退出**：首笔入场成交满 24 小时，在下一条行情事件市价平仓。
   数据中断期间不能保证按时成交。保护单取消、拒绝或修改失败时也转入市价退出，
   退出未完成时后续行情重试。不会影响其他策略的订单。
6. **定仓**：每笔计划风险为当前账户权益的 0.5%；按止损距离，加上入场和止损
   名义金额各 0.07% 的成本缓冲计算数量，向下取整至合约数量步长。
   名义金额最多为账户权益的 1 倍。账户 5 倍杠杆只是保证金设置，不代表使用 5 倍仓位。
7. **数据缺口**：不完整的聚合 K 线不输出；缺失小时后的指标窗口重新预热；
   缺失日线后重新积累 20 根连续日线。最新应收盘日线缺失时，旧日线背景立即失效。

周期和倍数可在 `config.py` 调整；默认值来自固定的开发/验证划分。
`fee_buffer` 是定仓缓冲，真实手续费由回测合约定义或交易所收取，不能用它代替成本扣除。
`close_positions_on_stop=True` 在回测末尾清仓，和策略的 24 小时时间退出是两项独立行为。
Nautilus 在停止之后不向策略投递队列中的末尾成交，最终清仓状态以引擎账户、订单、持仓报告为准。
本项目目前不提供该策略的实盘启动对账、崩溃恢复或历史资金费率重放。

## 运行

```bash
.venv/bin/python -m strategy_python.pullback_short_1h.backtest \
  --start 2021-01-01 --end 2026-09-01

.venv/bin/python -m strategy_python.pullback_short_1h.backtest \
  --start 2025-01-01 --end 2026-09-01
```

时间为 UTC，结束时间不包含。500 USDT 初始资金，30 天预热。
默认不联网补数据。支持公共 `--interval`、`--check-data` 等参数；输入支持 1s、1m、5m。
`--reward-risk` 和 `--max-holding-hours` 可做明确的参数对照。
Python `run_backtest(start,end,**parameters)` 可覆盖其他静态参数。

组合注册名为 `pullback_short_1h`。可在新组合清单中添加：

```json
{"id":"PBS","strategy":"pullback_short_1h","enabled":true,"parameters":{}}
```

目前仅支持 `risk.mode="none"`；单笔风险限制不能代替组合共享预算。
注册不会自动改变已有三策略清单。

## 实验记录

开发期为 2021–2023 年；2024 年用于验证筛选；参数固定后才评价 2025 年至
2026 年 8 月保留区间。共筛选 294 个组合，早期失败实验也保留，不能把整个历史区间
称作样本外，也不能把筛选后的正收益当作未来盈利保证。

[实验与验证记录](../_report/analysis/pullback_short_20260913/结果说明.md)记录原生回测、
浮动权益回撤、成本敏感性、年度盈亏以及数据缺口。
