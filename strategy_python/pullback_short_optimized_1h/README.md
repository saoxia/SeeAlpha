# 小时反弹做空：保留验证期胜出的原规则

[参数计算公式与来源](PARAMETER_SOURCES.md) · [缺乏校准依据的待讨论项](../PARAMETER_QUESTIONS.md)

**评估结论：保留原组合规则。本轮未找到同时通过开发、验证的改进。**

2025-01-01 至 2026-09-01 留出期，500 USDT 独立起步：原版净收益 126.62，新版 126.62 USDT；分钟收盘权益回撤 14.24% → 14.24%。该区间曾被原策略研究使用。

独立主类：`PullbackShortOptimized1hStrategy`。

本轮 12 个候选中，没有改动同时通过开发期与验证期的改进门槛，因此选择 **`baseline`**。该目录是独立的新版本，但不能宣称交易规则或收益已经提升。

日线背景：最近完整日线低点跌破 BOLL(20,2) 下轨且收盘低于中轨。小时信号：上一根小时收盘不低于 SMA20，本根小时收盘跌回 SMA20 下方。结构止损为近 12 个完整小时最高价 + 0.25 × ATR14，止损距离限制为 0.4%–3%，止盈为 4R，成交满 24 小时后按原规则市价退出。

新文件默认 `risk_fraction=0.015`、`max_notional_fraction=3.0`，来自**原四策略组合**的覆盖参数。本次原版基准也使用这两个数值；相对于原组合没有加大风险。原单策略目录的 0.005/1.0 默认值并非本次组合基准。

保留原规则的原因：单独改为 5R，开发期净收益从 48.34 提升到 54.73 USDT，但验证期从 44.11 降到 35.55；24 小时结构配合 5R，开发期为 73.99，但验证期为 −9.44 USDT。不能因开发期更高而采用验证退步的参数。

## 运行与结果

回测与交易使用同一个 Strategy 类。本目录不导入原策略目录；`config.py`、指标/信号、风险、执行和运行状态分别负责各自职责。

```bash
.venv/bin/python -m strategy_python.pullback_short_optimized_1h.backtest --start 2021-01-01 --end 2026-09-01
```

500 USDT 初始资金、5 倍账户保证金杠杆；默认只读本地行情。完整参数及候选选择在 `config.py`、`selection.json`，运行报告保存到统一 `_report/backtest/`。

选择仅使用 2021–2023 开发期及 2024 验证期；2025–2026 年 8 月为本轮固定参数后的留出评估，但历史上曾用于原策略研究，不能称为完全未见数据。
