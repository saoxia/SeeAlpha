## 本机开发状态

本机未迁移原始观察数据、冻结清单和后台任务，不能续接或评估旧观察。
原有系统后台配置已移除；Python 采集、核验和评估代码保留，便于后续开发。
新观察需单独建立研究目录、起点和冻结记录，再进行运行验收。

## 数据与核验

全部写入 `data/forward_validation/btc_eth_mrl_20260921/`，不混入旧回测数据。`raw/` 保存公开接口原始响应，`observations.sqlite` 保存行情、模拟报价、触价证据、成本、故障及响应哈希链；`frozen_sources.zip` 为启动时源码归档。

启动前检查覆盖原策略特征一致性、缺口重新预热、真实报价生效时间、成交量条件、中断重放去重、手续费和资金费、缺失未来数据、公开接口限制以及到期评估门槛。相关测试在 `tests/forward_validation/observer_test.py`。

保守触价仍不能证明实际排队成交。固定手续费假设、收盘退出代理及匹配样本之间可能残留的相关性，都限制结果的实际交易解释；区块重抽样和成本压力不能消除这些限制。
