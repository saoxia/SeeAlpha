# TRADE 专业指标库与策略信号显示

**产品定位**：这里的专业指标能力服务于 **TRADE 手动交易/手动下单**，并不意味着该页承载完整的策略研究与回测功能。策略研究、回测复盘是否纳入 TRADE 已列为[待评估开发功能 FE-001](FEATURE_EVALUATION_BACKLOG.md)；在产品评估并明确授权之前，保留既有图表能力，不主动接入策略事件或新增回测控制。


## 入口与使用

1. 打开 `TRADE`，点击 K 线周期右侧的 `ƒx`。
2. 在独立指标库里搜索名称/代码，按分类选择，点击「＋ 添加」可连续添加，不必反复打开弹窗。
3. 在 K 线左上角的指标标签上，悬停可进行隐藏/显示、设置、上下排序、删除。移动有独立副图的指标会改变副图顺序。
4. 「设置」分为参数、样式、可见性三个标签。可见性未选择具体周期时表示所有周期。
5. 在设置中调节副图相对高度（1–6）。图表里的主图/副图由现有 Lightweight Charts panes 绘制，并未替换引擎。
6. 指标库侧边栏的「我的收藏」「已添加」「指标模板」提供快捷入口；模板最多 20 组。模板应用时生成新的指标实例 ID。

收藏、模板与副图高度持久化在当前浏览器 `seealpha.chart.study-workspace.v1`。已存在的 `seealpha.chart.indicators` 仍可读取。浏览器存储不可用时功能可用但不保证刷新后恢复。没有跨设备共享，也不会写策略后端。

## 自定义公式

选择 CUSTOM 后，在「参数」里填写公式，例如：

- `SMA(close, 20)`
- `EMA(close, 9) - EMA(close, 21)`
- `ABS(high - low)`
- `ROC(close, 12)`

字段包括 `open/high/low/close/volume/hl2/hlc3/ohlc4`，支持四则运算、数字常量、括号和 SMA、EMA、ROC、ABS。周期限制为 1–500 的整数，公式限制为 160 字符、64 个词元；指标不够预热时返回空值，除零结果也显示为空值。该解释器不会执行 JavaScript、网络请求或任意 Python 代码。自定义公式可绘制在主图或单独副图。指标实例及其公式可以保存在本地模板。

## 图表信号与策略事件边界

内置 SIGNAL 指标只根据当前加载的 K 线计算双均线交叉，在图表绘制金叉/死叉箭头。它是**图表研究提示**，不是已运行策略的真实信号。

`MarketChart` 另定义了可选的只读 `strategySignals` 属性：

```ts
type ChartSignal = {
  id: string;
  time: number; // UTC 秒时间戳，必须匹配当前 K 线 time
  direction: "buy" | "sell";
  label: string;
  source: "chart" | "strategy";
};
```

业务侧未来从经过授权的回测/策略报告获取事件时，可在构建好 `strategySignals` 后传给 `MarketChart`。输入经 `sanitizeChartSignals` 校验、去重和数量限制，并只投影当前 K 线时间范围；策略来源在标记文案上显示「策略·」。当前 `TRADE` 页面**尚未连接**真实回测或策略运行报告；因此没有策略事件时不显示「策略·」标记。不能把市场显示 K 线或浏览器计算结果反向当作执行证据，不能从此通道发送、撤销订单。

## 设计边界

- 前端无动态 `eval`，无自定义脚本执行。
- 不变更账户、交易所 connector、Nautilus 风控/执行和已有下单路径。
- 系统级策略执行信号进入图表前必须由后端只读 API 给出来源、策略实例身份、事件时间和权限校验；该接线不属于当前前端指标库交付。
- 前端测试包括语法安全、预热、保存恢复和信号验证；变更 PR 的 Frontend CI 检查测试、Lint 与生产构建。
