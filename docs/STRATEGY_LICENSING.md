# Strategy licensing / 策略包授权边界

本仓库的 Platform 核心代码采用 Apache-2.0；`strategy/demo_*/` 官方演示包各自提供 MIT `LICENSE`（拟授权范围须经权利来源复核）。示例只用于研究与教学，不承诺盈利、实盘资格或风险保护效果。

## User-owned strategy packages / 用户策略

- 用户上传或创建的原创策略，著作权通常仍归合法权利人；上传到策略库、选择 private/public 或复制包本身不构成对源代码的公共开源授权。
- 策略库的 public/private/shared 是**软件访问控制状态**，不是版权许可证的名称。公开可见或可复制不自动授予第三方再分发、商用等权利。
- 系统必要的运行许可、平台托管服务条款、付费策略订阅权利须通过独立的用户/商业协议约定；本文件不擅自授予平台超出运行所需的额外授权。
- 对官方 MIT Demo 复制和改造时，应保留许可与版权声明；第三方包必须遵守各自适用的授权。
- 策略是否因与 Engine 的导入/组合构成衍生作品，应按真实代码关系与所用第三方许可判断；不应仅因以 ZIP 交付就断言所有策略不受外部许可证影响。
- 用户在产品内上传、共享或运行策略不构成向 GitHub 开源仓库提交贡献，**不适用社区 CLA 签署流程**。

## Proprietary subscriptions / 私有商业策略

官方可以另行提供付费策略许可、托管、风险对冲方案与顾问服务；对应交易策略的交付、使用、修改和转售权利应由独立订阅/策略合同约定。金融风险对冲不等于保本承诺，也不自动构成具有保险法律意义的承保业务。
