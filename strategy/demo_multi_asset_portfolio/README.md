# ETH 现货 + BTC 永续跨标的原生组合回测 Demo

**仅供开发研究，不是交易建议或盈利策略，也不具有实盘下单权限。**

本 Demo 故意采用最简单的固定仓位目标：`+0.05 ETHUSDT Spot`、`-0.001 BTCUSDT USD-M`。其目的只是验证一个已下发策略同时订阅两个不同产品/标的并发表两个目标，SeeAlpha 聚合后用 **同一个 NautilusTrader BacktestEngine** 产生原生订单和模拟成交。ETH/BTC 之间不存在自动完美对冲关系。

## 在 Platform 中运行

在开发租户的 USDT 虚拟账户中下发本策略（默认参数即可），打开组合开发回测，选择「通用多标的 · 原生模拟（开发）」、勾选本下发实例编号，配置市场腿：

```
spot:ETHUSDT
futures_um:BTCUSDT
```

先为两条腿准备**相同窗口**的 1m 或 5m 历史 K 线、原生合约定义及租户订阅，分别配置 Spot CASH 与 USD-M MARGIN 起始资金和总毛名义风险预算。所有历史数据缺失、未授权、资金或数量异常都应阻断回测。不需要配置真实交易密钥。

该固定仓位示例不包含资金费结算核验、期权组合、真实盘口成交模拟或完整的实盘跨腿恢复。回测结果仅为原生 K 线模拟成交和分账户权益。
